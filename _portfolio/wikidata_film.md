This project is an interactive web application for exploring relationships between films using data from Wikidata. Its central feature is a network map connecting films through shared attributes, complemented by detailed information pages and visualisations. The application combines a React front end, JavaScript back-end services, a REST API and an SQLite database containing approximately 15,000 films.

My main focus was developing the database API using Node.js, Express and SQLite. I implemented flexible endpoints for searching, filtering, sorting and finding related films, implemented using dynamically constructed SQL queries. The API was documented using Swagger and OpenAPI. I also contributed to the application’s front end in React and the database back end. We used GitLab for version control and collaborative development, and deployed the application through a CI/CD pipeline using Docker. There was also a particular emphasis on accessible design with features such as keyboard navigation, contrast and dyslexic-friendly font options.

The project gave me experience in full stack development, including databases, API design, web programming and visualisations. Working with a larger team also strengthened my understanding of modular architecture and effective communication between developers managing different components.
